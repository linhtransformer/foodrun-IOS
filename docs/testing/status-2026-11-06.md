## What I think is not ready yet

1. **Dark mode is new and only partly looked at.** The colours follow the switch everywhere, but most
   screens were designed for light only. Expect a few spots (sheets, chips, maps, the black shift card)
   that need a second look before it's a feature to show customers.
2. **The availability deadline went back and forth.** It is correct now (Thursday, 0 = Monday), but it was
   wrong on build 11. Check the "Sluit …" pill once on build 12.
3. **Clocking has many paths and the simulator can't test NFC.** Tag, button, overnight, forgotten
   clock-out, double scan and wrong truck each work once on the phone, but each was tested once. A short
   real-world trial with one truck and two people for a week would catch what single tests don't.
4. **Notifications are thin.** Only roster changes reach the phone; hours decisions, swaps and tasks land
   in Berichten without a push. Fine for now, but crew will miss things if they don't open the app.
5. **Account creation is untested end to end.** The form works; making an account, the confirmation mail
   and the first login after it have not been run on a real address.
6. **Apple / Google sign-in and AutoFill** have not been tried since the redesign.
7. **Test data drift.** The test company has been re-seeded and edited by both sides (Sanne was deleted by
   one mis-tap once). Before showing the app to anyone, re-seed it so the screens look clean.
